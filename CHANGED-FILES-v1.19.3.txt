BAGIAN BARU SESI INI — PERBAIKAN STYLE UI MODUL ANALITIK
==================================================================
Masalah yang dilaporkan: revisi modul Analitik sebelumnya (v1.19.2) "tidak
berjalan" / tampilannya tidak sesuai aplikasi. Root cause & perbaikan:

1. views/analytics/index.ejs — REBUILD ULANG TANPA TAILWIND
   Versi v1.19.2 memuat Tailwind CSS via CDN terpisah untuk halaman ini saja.
   Ini membuat tampilan Analitik terlihat berbeda sendiri dari sisa aplikasi
   (yang memakai Bootstrap + design system CSS var kustom di public/css/app.css)
   dan menambah dependensi CDN eksternal yang tidak dipakai halaman lain.
   Halaman ini sekarang ditulis ulang 100% memakai kelas/komponen yang SUDAH
   ADA di aplikasi: module-head, analytics-v119 (analytics-tabs, analytics-pane,
   analytics-kpi-grid, analytics-advisory-card, analytics-chart-card,
   analytics-aging-card, analytics-psb-grid, analytics-funnel-card,
   analytics-sla-card, odp-heatmap), app-table, status-badge, cell-main/cell-sub,
   approval-button (dipakai ulang utk tombol WA Reminder), btn-tech, serta modal
   Bootstrap native (data-bs-toggle/data-bs-dismiss) — pola yang sama persis
   dengan modal-modal lain di aplikasi (proofUploadModal, cashRejectModal, dst).
   Semua fitur baru dari v1.19.2 tetap dipertahankan: Dual-Matrix Cash/Accrual,
   Matrix Jatuh Tempo 15 vs 30 + rekonsiliasi overlap tgl 6-7, Smart Advisory
   Engine 3-rule, filter cepat Aging Piutang (Semua/H-3/H+3~30/>30/Siap Isolir),
   tombol WA Reminder per pelanggan, ODP Capacity Heatmap dengan badge, dan
   modal "Generate Laporan Analitik" (fetch /analytics/export-report, tombol
   Cetak/PDF via window.print(), Kirim ke Owner via WhatsApp, Unduh JSON).
   Hanya tampilannya yang dikembalikan ke bahasa desain aplikasi asli.

2. public/css/app.css — PERBAIKAN BUG VARIABEL CSS (root cause tampilan patah)
   Ditemukan: blok CSS .analytics-v119 / .infra-v119 / .cash-approval-* (semua
   fitur "v1.19") memakai var(--border) dan var(--card) di banyak tempat, TAPI
   kedua custom property ini TIDAK PERNAH didefinisikan di :root atau di blok
   tema (yang ada hanya --line dan --panel dengan nama berbeda). Akibatnya
   border & background kartu-kartu di modul Analitik, Infrastructure Hub, dan
   Cash Approval berpotensi tidak tampil (invisible) karena browser menganggap
   var(--border)/var(--card) yang tidak terdefinisi sebagai nilai tidak valid.
   Perbaikan: menambahkan alias --border:var(--line) dan --card:var(--panel)
   pada kedua blok tema (html[data-theme="dark"] dan html[data-theme="light"]),
   sehingga SEMUA komponen v1.19 (bukan cuma Analitik) sekarang benar-benar
   tampil dengan border & latar kartu sesuai desain aslinya di kedua tema.
   Juga ditambahkan sedikit CSS baru yang dipakai halaman Analitik: chip filter
   Aging Piutang (.aging-filters) dan kartu mini-stat (.analytics-mini-stats)
   untuk panel rekonsiliasi & modal laporan — ditulis mengikuti bahasa desain
   yang sama (var(--border), var(--card), var(--muted), border-radius, dsb).

3. scripts/validate-v119.js
   Assertion 'analytics module' dikembalikan untuk mencocokkan teks asli
   (SMART ADVISORY ENGINE / CASHFLOW STREAM / PSB CONVERSION FUNNEL / ODP
   CAPACITY HEATMAP dalam huruf kapital, sesuai konvensi aplikasi), ditambah
   pengecekan eksplisit BAHWA halaman ini TIDAK lagi memuat Tailwind CDN, dan
   pengecekan baru bahwa alias --border/--card sudah ada di app.css.
